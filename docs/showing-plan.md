## 2. 쇼잉 전략

- **관점**: 기능 목록이 아니라 *한 사람의 하루*. 아침 기록 → 저녁 관리 → 내일 루틴으로 이어지는 순환이 Trac:ing의 정체성(“하루를 이어서 기억하는 거울”)이므로, 장면 순서를 하루의 시간 순서와 맞춤.
- **첫 장면 = 실제 UI 이미지(미러 HOME)**: 실사용 영상·사진 자료가 없음. 반면 HOME 화면은 “어제 기록으로 오늘 피부를 먼저 알려 주는 거울”이라는 핵심을 한 장으로 보여 줌. 큰 워드마크(표지 디자인) + 실제 화면 조합으로 정체성과 서비스를 동시에 소개함. 사용 장면 영상은 마무리 영역에 교체용 자리로 둠.
- **기능 장면 규칙**: 사용 전 → 사용자 조작 → 화면 변화 → 사용 결과. 실제 화면 위 버튼 위치에 조작 영역(TAP)을 두어 누르면 다음 상태로 전환함.
- **비중**: 핵심 기능(아침 안내, 저녁 스캔, 기기 연동)은 큰 화면 + 4단계 상태 전환. 보조 기능(타이머, 음성, 범례, 변화 화면)은 카드나 확대 화면으로 설명.

## 4. 참고 사이트에서 가져온 원리 (확인한 범위 안에서)

- **이미지 먼저, 설명은 그다음** (artless의 프로젝트 블록 순서: 제목 → 분야 한 줄 → 이미지 → 상세 설명): 각 장면에서 실제 화면을 먼저 크게 보여 주고 설명은 옆 패널로 짧게 둠.
- **짧은 제목, 한 줄 키워드, 그 아래 상세** (artless 제목·분야 줄 분량, 기획서 10장 “상단 핵심 메시지 / 하단 키워드·상세 설명”): 장면 머리말 = 번호·영문명·한글 키워드 한 줄 → 큰 제목 한 줄 → 2줄 설명.
- **큰 크기 대비** (기획서 11장 레퍼런스의 대형 타이포 + 전체 폭 이미지): 워드마크 280px급 / 섹션 제목 76px Light / 본문 17–19px. 왼쪽 정렬 그리드.
- **전체 폭·분할·확대·연속 배치**: 도입은 전체 폭 무대, 연결은 분할, 변화는 확대 화면, 화면 모음은 가로 연속 스크롤.
- **배경색으로 만드는 리듬**: 기본 #FAFAFA → 리서치 회색 → 컨셉 흰색 → 인덱스 어두운 회색 → 아침(따뜻한 회백) → 저녁(차가운 회청) 순으로 하루의 시간감을 배경에 반영. 섹션 간격 96–200px.
- Plus X 사례의 구조 분석은 사이트가 열리지 않아 반영하지 못함.
