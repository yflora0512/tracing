## 2. 쇼잉 전략

- **관점**: 기능 목록이 아니라 *한 사람의 하루*. 아침 기록 → 저녁 관리 → 내일 루틴으로 이어지는 순환이 Trac:ing의 정체성(“하루를 이어서 기억하는 거울”)이므로, 장면 순서를 하루의 시간 순서와 맞춤.
- **첫 장면 = 실제 UI 이미지(미러 HOME)**: 실사용 영상·사진 자료가 없음. 반면 HOME 화면은 “어제 기록으로 오늘 피부를 먼저 알려 주는 거울”이라는 핵심을 한 장으로 보여 줌. 큰 워드마크(표지 디자인) + 실제 화면 조합으로 정체성과 서비스를 동시에 소개함. 사용 장면 영상은 마무리 영역에 교체용 자리로 둠.
- **기능 장면 규칙**: 사용 전 → 사용자 조작 → 화면 변화 → 사용 결과. 실제 화면 위 버튼 위치에 조작 영역(TAP)을 두어 누르면 다음 상태로 전환함.
- **비중**: 핵심 기능(아침 안내, 저녁 스캔, 기기 연동)은 큰 화면 + 4단계 상태 전환. 보조 기능(타이머, 음성, 범례, 변화 화면)은 카드나 확대 화면으로 설명.

## 4. 참고 사이트에서 가져온 원리 — Plus X “UNIX” 쇼잉 중심

2차 수정(2026-11-24)에서 사용자 요청에 따라 UNIX 상세 쇼잉의 구조를 적극 적용했습니다.

| UNIX 쇼잉에서 확인한 원리 | Trac:ing 적용 |
| --- | --- |
| 첫 화면 = 하늘 영상 + 영문 태그라인 한 줄(“The New Breath of Everyday”) + 하단 작은 크레딧 | 숨 쉬듯 움직이는 하늘색 그라데이션 + 점선 트레이싱 얼굴이 그려지는 키 비주얼, “The Mirror That Remembers Your Day” |
| 좁은 본문 블록(787px, 굵은 라벨 + 15px 본문) ↔ 전체 폭 이미지·영상 교차 | 모든 설명을 790px 블록(라벨 + 본문 2~4줄)으로 통일, 사이사이 전체 폭 커버·데모 밴드 |
| 목차 슬라이드(로고 왼쪽, 장 목록 오른쪽, 연회색) | 같은 구성의 Index 슬라이드, 항목 클릭 시 해당 장면으로 이동 |
| 회색 배경 대형 문장 슬라이드(Mission / Vision) | Concept / Keywords 문장 슬라이드 |
| 1978–2023 / 2024 두 장의 세로 카드 비교 | Before(따로 노는 화장·관리) / With Trac:ing(하나로 이어진 하루) |
| 실제 맥락 속 제품(빌보드·에코백) | 탁상 미러 렌더링 위에 실제 HOME 화면 |
| 번호 붙은 Design Summary 콜라주, 비대칭 컬러 시스템, 대형 타입 견본 | 01–03 콜라주(트레이싱 도식·타이머·음성), 엇갈린 컬러 칩, “가Aa” 견본 |
| Brand Voice 슬라이드(왼쪽 텍스트·번호 목록·컬러 바) | Mirror × Mobile 연동 섹션 머리 |
| 지오메트릭 산세리프(Pangram Sans) + Pretendard | Outfit(영문 디스플레이) + Pretendard(국문) |
| 마지막 크레딧 | Credit 블록 |

UNIX는 브랜드 아이덴티티 프로젝트라 화면 조작이 없지만, Trac:ing은 과제 조건(누르면 → 바뀌고 → 결과)에 맞춰 각 장면 커버 뒤에 직접 눌러 보는 데모를 크게 배치했습니다.

## 6. 추가 자료가 필요한 부분

- 12주차 1:1 피드백 원문 기록 (현재는 화면 설계 슬라이드의 3가지 피드백으로 대체)
